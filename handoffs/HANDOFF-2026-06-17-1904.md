## Dead Ends — Do Not Retry

### Frontend build in Claude Code's Bash context
| Approach Tried | Why It Failed |
|----------------|---------------|
| `npm run build` with Vite 5 / Rollup 4 | Windows Application Control blocks `@rollup/rollup-win32-x64-msvc.node` with `ERR_DLOPEN_FAILED` |
| Clean reinstall then retry | Binary is re-downloaded identical; still blocked |
| Delete `@rollup/rollup-win32-x64-msvc` dir to force WASM fallback | Rollup 4's `native.js` throws `MODULE_NOT_FOUND` with same friendly error — no actual WASM fallback in this version |

**What to try instead**: Downgrade Vite to `^4.5.0` (already done). Rollup 3 = pure JS, no native binary, no policy issue.

### Running the backend from Claude Code's Bash context
| Approach Tried | Why It Failed |
|----------------|---------------|
| `python -m uvicorn backend.main:app ...` | Windows Application Control blocks `pydantic_core`'s compiled `.pyd` extension — same policy |

**What to try instead**: Always run the backend in the user's own PowerShell terminal. Claude Code can edit files and build the frontend (Vite 4); the backend must be started by the user.

### RECALL_MAX_DISTANCE = 1.0
| Approach Tried | Why It Failed |
|----------------|---------------|
| Default threshold from handoff plan | Cosine similarity threshold of 0.5 is too strict — question phrasing ("where is my charger") vs. scene description ("desk with electronic accessories") semantic gap pushes real hits above 1.0 |

**What to try instead**: 1.4 (current). Calibrate down toward 1.1 if false positives appear; watch server console `top_dist=` lines.

## Key Decisions

- **Vite 4 pinned** (`"vite": "^4.5.0"` in `package.json`): Trade-off — slightly older toolchain, but fully functional. Vite 5 blocked by Windows App Control on this machine.
- **Auto-restart in `_runner`, not in `run_live`**: The audio queue is shared across restarts; keeping it alive in `_runner` avoids reinitializing the WS message plumbing.
- **`asyncio.to_thread` for ChromaDB**: It's a synchronous blocking call; running it inline would stall audio delivery from the receive loop.
- **RECALL_MAX_DISTANCE = 1.4**: Just under √2 ≈ 1.414 (L2 distance for fully orthogonal unit vectors); accepts anything with any semantic overlap. Reduce toward 1.1 if wrong objects start being recalled.
