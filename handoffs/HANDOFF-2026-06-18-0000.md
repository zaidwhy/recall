## Current architecture

```
Phone (HTTPS via cloudflared tunnel)
  │
  ├─ video frames every 2s ──► last_frame.jpg
  │
  │  _ingest_loop (every 5s):
  │    has_scene_changed() → numpy pixel diff
  │    gap check (120s) + budget check (18/day)
  │    → send "scanning" to frontend
  │    analyze_frame() → gemini-2.5-flash
  │    log_observation() → ChromaDB
  │    → send "ingested"/"updated" + next_scan_at
  │
  ├─ mic audio → Gemini Live (gemini-3.1-flash-live-preview)
  │    recall_memory() tool → ChromaDB (time-decay re-rank)
  │    → "recalled" WS event → spotlight card
  │
  └─ WS messages: scanning / ingested / updated / recalled / transcript / record_status / error
```

## Known constraints

- **20 RPD hard limit** on `gemini-2.5-flash` free tier. Quota resets at midnight (Google's time).
- **`_flash_calls_today` resets on server restart** — Google's counter does not. If you restart the server mid-day, the on-screen count restarts at 0 but Google's real count continues.
- **Auto-record on every WS reconnect** — intentional (demo UX). If you stop recording manually and the tunnel reconnects, recording resumes.
- **Windows App Control** — was the blocker for running backend in Claude Code Bash. User turned it off. Now `python -m uvicorn` works from Bash.
