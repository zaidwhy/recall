## Key Decisions

- **`_flash_blocked()` returns a message string, not bool** — lets callers send the exact reason to the client without knowing rate-limit internals. `None` = allowed; non-None string = blocked + explanation.
- **`DELETE /memory` (no ID) for clear-all** — clean REST semantics; FastAPI resolves `/memory` and `/memory/{entry_id}` without conflict because the parameterized route only matches when there's an additional segment.
- **`list_locations` added to same `RECALL_TOOL` `function_declarations` list** — keeps one `tools=[RECALL_TOOL]` in `LiveConnectConfig`; no extra config arg.
- **Stats bar only appears when `timeline.length > 0`** — avoids showing "0 memories · 0 locations" during onboarding; cleaner cold-start UX.
- **Auto-dismiss error at 8 s** — short enough to feel responsive, long enough to read a 2-line message on mobile.
